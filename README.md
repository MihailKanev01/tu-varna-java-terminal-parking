# Automated Parking Model

A Java object-oriented study project for modelling an automated parking facility and different types of vehicles.

## Overview

The source includes a shared vehicle model and specialised types such as cars, buses, motorcycles and trucks. Supporting classes represent parking places, premises, vehicle dimensions, volume, engine types and charging-related concepts.

## Concepts Demonstrated

- Object-oriented domain modelling
- Inheritance and specialised vehicle types
- Composition between vehicles, parking places and a parking facility
- Modelling vehicle capacity and physical dimensions

## Technology

- **Language:** Java
- **Project type:** Educational console/domain-model exercise
- **Source:** `src/automated_parking/`

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/MihailKanev01/tu-varna-java-terminal-parking.git
   cd tu-varna-java-terminal-parking
   ```
2. Open the project in IntelliJ IDEA or another Java IDE.
3. Compile the source files and inspect the model classes.

The current source tree contains the domain model; verify the available entry point in the IDE before attempting to run it as a standalone application.
